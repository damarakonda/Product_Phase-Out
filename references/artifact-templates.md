# Artifact Templates

Use these structures when the user asks for deliverables.

## Phase-Out Charter

| Field | Content |
| --- | --- |
| Product scope | Product family, model, version, accessories, software, service parts |
| Phase-out type | End-of-sale, end-of-manufacture, end-of-service, discontinuance, withdrawal, software end-of-support, other |
| Reason | Business, supply, quality, regulatory, cybersecurity, replacement launch, obsolescence |
| Markets | Countries/regions and regulatory status |
| Installed base | Units, customers, versions, critical-use segments |
| Target dates | Last order, last ship, end install, end service, end spares, end software support |
| Replacement path | Upgrade, alternate product, extended service, exception, no replacement |
| Key risks | Patient safety, regulatory, supply, cyber, customer, contract, revenue |
| Governance | Sponsor, accountable owner, approvers, steering cadence |

## Executive Brief

Use this structure for leadership-ready summaries:

1. Decision requested or decision made.
2. Product and market scope.
3. Why phase-out is needed now.
4. Patient, customer, regulatory, quality, cybersecurity, and financial impact.
5. Recommended timeline.
6. Top risks and mitigations.
7. Approvals needed.
8. Open decisions and data gaps.
